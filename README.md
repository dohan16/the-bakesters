# 🍪 The Bakesters

A premium bakery e-commerce website built for **The Bakesters**, featuring a modern product catalogue, WhatsApp ordering, and a secure admin dashboard for managing products.

## 🌐 Live Website

👉 https://thebakesters.netlify.app/

## ✨ Features

- 🛍️ Premium bakery product catalogue
- 🍪 Product categories and filtering
- 🛒 Shopping cart functionality
- 📱 WhatsApp ordering integration
- 📦 Dynamic product stock management
- 💰 Dynamic pricing
- 🖼️ Product image management
- 🔐 Admin authentication
- ⚙️ Admin dashboard for adding, editing and deleting products
- 🗄️ Supabase database integration
- 🚀 Netlify deployment
- 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Netlify
- WhatsApp API
